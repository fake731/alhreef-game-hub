# Alhreef Gaming Hub

بناء موقع احترافي لمحل ألعاب — Alhreef Store

أريد إنشاء موقع إلكتروني احترافي وكبير ومتكامل لمحل ألعاب، وليس صفحة هبوط بسيطة. اسم المحل وشعاره سأرفقهما لك كملفات، ويجب أن يكون التصميم بالكامل مبنيًا حول اللوجو والهوية البصرية للمحل.

1. الهوية البصرية والتصميم

سأرسل لك لوجو المحل كملف، استخدمه كمرجع أساسي للهوية البصرية.

استخرج من اللوجو الألوان الأساسية والثانوية واستخدمها في:

الخلفيات.

الأزرار.

العناوين.

البطاقات.

الحدود والتفاصيل.

الـ Hover effects.

عناصر الموقع المهمة.

لا تستخدم ألوانًا عشوائية لا تتناسب مع اللوجو.

اختر خطًا عربيًا رئيسيًا مناسبًا جدًا للوجو وهوية محل الألعاب، وخطًا ثانويًا متناسقًا معه.

سأرسل لك أيضًا ملفات/صور إضافية، استخدمها كمرجع بصري.

التصميم يجب أن يكون راقيًا، عصريًا، شبابيًا، Gaming Store Premium وليس تصميمًا طفوليًا.

لا تستخدم أيقونات أو رسومات توحي بأن التصميم مولّد بالذكاء الاصطناعي.

استخدم Icons احترافية وبسيطة ومتناسقة، ويفضل أن تكون من مكتبة Icons احترافية معروفة.

لا تضع أي نصوص أو عناصر تجريبية مثل "AI Generated".

لا تستخدم صورًا عشوائية بدل الصور التي سأرسلها.

إذا لم أرسل صورة لعنصر معين، استخدم Placeholder أنيقًا ومؤقتًا بدل اختراع صورة غير مناسبة.
